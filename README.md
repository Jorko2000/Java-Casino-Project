 Java-Casino-Project
The system is a secure, server-side casino gaming backend built with Java and Spring Boot. It simulates how real iGaming platforms operate, focusing on fairness, security, concurrency, and fraud prevention, rather than just game visuals.
Casino Gaming Platform (Java / Spring Boot)


Secure casino backend demonstrating real iGaming concepts: fairness, RTP, concurrency, fraud prevention.


 Features
- Server-side RNG
- Wallet concurrency safety
- JWT authentication
- Anti-bot & anti-fraud
- RTP monitoring
- Dockerized deployment


 Run
mvn clean package
java -jar target/*.jar
